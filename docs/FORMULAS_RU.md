# Формулы SellerMoney Pro

## Базовая логика

```text
Комиссия = Цена × комиссия %
Эквайринг = Цена × эквайринг %
Реклама = Цена × реклама %
Налог УСН 6% = Цена × 6%
Возвратный риск = Возвраты % × (возвратная логистика + логистика × 35% + упаковка × 20%)
Чистая прибыль = Цена - себестоимость - упаковка - логистика - хранение - комиссия - эквайринг - реклама - налог - возвратный риск
Маржа = Чистая прибыль / Цена × 100%
ROI = Чистая прибыль / (себестоимость + упаковка + логистика) × 100%
Потенциал в месяц = Чистая прибыль × продаж в месяц
```

## Точка безубыточности

В frontend используется итерационный бинарный поиск цены, при которой чистая прибыль становится >= 0. Это надёжнее, чем одна формула, потому что налог УСН 15% считается от положительной прибыли.

## Статусы

```text
profit < 0 или margin < 0 => Убыточный
margin < 8% => На грани
margin >= 8% => Прибыльный
```

## Важно

Формулы не заменяют бухгалтерию и фактические отчёты маркетплейсов. Это инструмент быстрого принятия решений перед закупкой, акцией или запуском рекламы.
